# Application Feature Demos
Source code samples demonstrate how to use and configure single yFiles WPF features. 

You will find the following programming samples in this package: 


| Name | Description |
|:---|:---|
|**Background Image** |This demo shows how to add a background to a graph. The background can be an image or a colored rectangle. |
|**Building Graphs From Data** |This demo uses the IGraph API to build nodes, nested groups, labels, edges, ports, and bends from JSON data. |
|**Building Swimlanes From Data** |This demo builds editable swimlanes from JSON, preserves lane assignments during automatic layout, and exports the graph to JSON. |
|**Complex Highlight Decorator** | Shows how to highlight nodes with different effects based on data stored in their tags. |
|**Custom Data in GraphML** | Shows how to read and write additional data from and to GraphML. |
|**External Links** |This demo shows how to add labels that act like external links and open in a new window. It only follows the external link on a Ctrl click and works directly with ILabel text, so you can add new labels that represent links. |
|**Filtering** | Shows how to configure graph filtering. |
|**Filtering With Folding** | Shows how to configure filtering and folding in the same application. |
|**Flow Filtering** |This demo demonstrates how to dynamically show or hide items within the connecting upstream or downstream flows of a given node. |
|**Folding** | Shows how to enable collapsing and expanding of group nodes. |
|**Folding With Merged Edges** | Shows how to enable the merging of edges when collapsing group nodes. |
|**Graph Copy** | Shows how to copy a graph or parts of a graph. |
|**Graph Decorator** | Shows how to decorate graph items to change their behavior or visualization. |
|**Graph Search** | Shows how to search for specific nodes in a graph. |
|**Grid Snapping** | Shows how to enable grid snapping during interactive changes. |
|**Heat Map** | Shows how to install a heat map renderer. |
|**Interactive Aggregation** |This demo shows how to analyze a graph by aggregating groups of nodes. Via the context menu, groups of nodes of the same color or shape can be aggregated, giving different insights about the graph. |
|**Label Text Wrapping** | This demo shows how to configure the text wrapping and trimming feature provided by the LabelStyle. Aside from wrapping in rectangular shapes, the TextWrappingShape property allows for wrapping in many more shapes like triangle, hexagon or ellipse. |
|**Octilinear Edge Editing** |This demo shows how to implement interactive editing of octilinear edges while preserving the routing style during editing operations. |
|**Orthogonal Edge Editing** | Shows how to enable interactive orthogonal edge editing. |
|**Overview Control** | Shows how to add an overview control to the application. |
|**Rectangular Indicator** | Shows how to add an interactive rectangular indicator to the graph control. |
|**Rotatable Nodes** | This demo shows how support for rotated node visualizations can be implemented on top of the yFiles library. <br /> A custom yWorks.Graph.Styles.INodeStyle implementation is used to encapsulate most of the added functionality. |
|**Simple Drag And Drop** |This demo shows how to use NodeDropInputMode for dragging nodes from a separate panel to drop them into the graph control. |
|**Simple Highlight Decorator** | Shows how to highlight nodes and edges when the mouse hovers over them. |
|**Theming** |Overrides XAML resources to customize graph interaction and overview indicators. |
|**Smart Click Navigation** |This demo shows how to navigate in a large graph, especially when only part of the graph is visible in the viewport. Click nodes and edges to move the view to a useful point of interest. |
|**Snapping** | Shows how to enable snapping (guide lines) for interactive changes. |
|**Subdivide Edges** | Shows how to subdivide an edge when a node is dragged on it. |
|**Table Editor** | Shows how to edit tables, rows, columns, and the graph elements they contain. |
|**Tooltips &amp; Popovers** | Shows how to enable tooltips and popovers for graph items. |
|**Viewport Limiter** |Shows how to use the viewport limiter to constrain the graph navigation. |

## Running the Demos

### With Visual Studio

* To load all samples into Visual Studio you can simply open the solution file yFiles Demos.sln. 
* To load a single sample into Visual Studio you can open the project file (.csproj) in the sample's directory.
