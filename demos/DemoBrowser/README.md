# The Demo Browser
A Demo Browser for easy finding and running demo applications. 

You will find the following programming samples in this package: 


| Name | Description |
|:---|:---|
|**Demo Browser** | The demo browser allows users to easily find and run demo applications by providing a comprehensive list of available demos. It also enables users to filter the demos based on search terms, making it easier to locate specific demos of interest. |

## Running the Demos

### With Visual Studio

* To load all samples into Visual Studio you can simply open the solution file yFiles Demos.sln. 
* To load a single sample into Visual Studio you can open the project file (.csproj) in the sample's directory.
