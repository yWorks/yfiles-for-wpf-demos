# Input Demos
These source code samples demonstrate how to configure specific aspects of the interaction functionality present in yFiles WPF. 

You will find the following programming samples in this package: 


| Name | Description |
|:---|:---|
|**Border-Aligned Label Model** | Shows how to implement a custom label model that positions labels around node borders. |
|**Circular Snapping** |Shows how to enable circular and angle snapping (guidelines) for interactive changes. |
|**Component Drag and Drop** |A demo that shows how to clear space for a dropped component in an existing layout. |
|**Context Menu** |Shows how to add a context menu to the nodes of a graph and to the canvas background. |
|**Custom Copy and Paste** |Shows how to copy and paste graph item styles. |
|**Custom Drag and Drop** |Shows how to change the color of nodes and edges using drag and drop operations. |
|**Custom Edge Creation** |Shows how to provide directional ports and demonstrates interactive routing during edge creation. |
|**Custom Handle Provider** |Shows how to implement custom handles that allow to interactively change the shape of an ArrowNodeStyle. |
|**Custom Port Location Model** |Shows how to implement and use a custom port location model. |
|**Custom Snapping** |Shows how the snapping feature can be customized. |
|**Drag and Drop** |Shows drag and drop of nodes, groups and labels. |
|**Drag From Component** |Shows how to drag graph items out of the graph component to another element. |
|**Edge Reconnection** | Shows how the reconnection of edge ports can be customized and restricted. |
|**Graph Drag and Drop** |Shows drag and drop of graphs consisting of multiple items. |
|**Interactive Graph Restructuring** | Shows how to interactively relocate subtrees from one parent to another. |
|**Label Editing** |Shows customizations of the interactive label editing. |
|**Label Handle Provider** |Shows how to implement custom handles that allow interactive resizing and rotation of labels. |
|**Lasso Selection** |Shows how to configure a lasso tool for freeform selection. |
|**Magnifying Glass** |Shows a floating lens that magnifies the cursor's surroundings. |
|**Marquee Node Creation** |Shows how to customize the MarqueeSelectionInputMode class to create new nodes. |
|**Mouse Wheel Customization** |Shows how to customize and enhance the default mouse wheel behavior. |
|**Move Unselected Nodes** | Shows a special input mode that allows you to move nodes without selecting them first. |
|**Node Selection Resizing** |Shows how to reshape a selection of nodes as one unit. |
|**Offset Wrapper Label Model** | Shows how to implement a custom label model that adds an adjustable offset to labels. |
|**Orthogonal Edge Editing Customization** | Shows how to customize orthogonal edge editing. |
|**Port Candidate Provider** | Shows how edge creation can be customized. |
|**Position Handler** | Shows how to customize and restrict the movement behavior of nodes. |
|**Reparent Handler** | Shows how reparenting of nodes can be customized. |
|**Reshape Handle Provider** |Shows how to add resize handles to ports. |
|**Reshape Handle Provider Configuration** |Shows how resizing of nodes can be customized. |
|**Restricted Editing** | Shows how to restrict interactive editing with GraphEditorInputMode. |
|**Single Selection** |Shows how to configure GraphEditorInputMode for single selection mode. |
|**Size Constraint Provider** |Shows how resizing of nodes can be restricted. |
|**Valid Begin Cursors** |Shows how various cursors can be used to indicate valid gestures at the current location. |

## Running the Demos

### With Visual Studio

* To load all samples into Visual Studio you can simply open the solution file yFiles Demos.sln. 
* To load a single sample into Visual Studio you can open the project file (.csproj) in the sample's directory.
