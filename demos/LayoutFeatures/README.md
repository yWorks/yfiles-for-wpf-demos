# Layout Feature Demos
These source code samples demonstrate specific features of the yFiles WPF layout algorithms. For more complex examples, please see the samples in [yFiles WPF Layout demos](../Layout). Examples which don't use the yFiles WPF viewer components are shown in the [yFiles WPF LayoutOnly demos](../LayoutOnly/LayoutOnly.md). 

You will find the following programming samples in this package: 


| Name | Description |
|:---|:---|
|**Bundled Edge Router** | Shows common configuration options for the bundled edge routing algorithm. |
|**Compact Disk Layout for Group Content** | This demo shows how to arrange the content of group nodes compactly with a circular layout. |
|**Compact Tabular Layout** | This demo shows how to configure the TabularLayout to create compact drawings. |
|**Hierarchical Layout with Constraints** | This demo shows how to customize layer assignment and node sequencing with constraints in the HierarchicalLayout algorithm. |
|**Edge Router** | This demo shows common configuration options for the EdgeRouter algorithm. |
|**Bus-Style Edge Routing** | This demo shows how to configure the EdgeRouter to generate orthogonal bus-style routes. |
|**Bus-Style Edge Routing (Custom)** | This demo shows how to configure the EdgeRouter to generate orthogonal bus-style routes with manually defined backbone points. |
|**Incremental Edge Router** | This demo shows how to run the edge router algorithm on a predefined subset of edges in a graph. |
|**Hierarchical Layout** | This demo showcases common configuration options for the HierarchicalLayout algorithm. |
|**Hierarchical Layout with Compact Groups** | This demo shows how to configure the HierarchicalLayout and CoordinateAssigner to draw compacter group nodes than default. |
|**Hierarchical Layout with Edge Grouping** | This demo shows how to customize the HierarchicalLayout to group edges at their source or target nodes. |
|**Hierarchical Layout with Edge Labeling** | This demo shows how to configure the HierarchicalLayout for automatic edge label placements. |
|**Incremental Hierarchical Layout** | This demo shows how to run the HierarchicalLayout algorithm in incremental layout mode. |
|**Hierarchical Layout with Node Alignment** | This demo shows how to configure the HierarchicalLayout to align nodes connected by critical paths. |
|**Hierarchical Layout with Node Port Candidates** | This demo shows how to use NodePortCandidates to define the port locations and limit the number of edges per port in HierarchicalLayout. |
|**Hierarchical Layout with Given Layering** | This demo shows how to customize the HierarchicalLayout to place nodes in a predefined layer. |
|**Hierarchical Layout with Layer Constraints** | This demo shows how to customize the assignment of nodes to layers (layering) when using HierarchicalLayout. |
|**Organic Layout** | Shows common configuration options for organic layout. |
|**Organic Layout with Constraints** | Shows how to configure constraints for the organic layout algorithm. |
|**Organic Layout with Edge Labeling** | Shows how to configure automatic label placement of organic layout. |
|**Incremental Organic Layout** | Shows how to run the organic layout on a predefined set of nodes. |
|**Organic Layout with Substructures** | Shows how to configure the layout of substructures in the organic layout. |
|**Orthogonal Layout** | Shows common configuration options for the orthogonal layout. |
|**Radial Group Layout** | Shows how to configure the radial group layout to arrange grouped graphs. |
|**Recursive Group Layout** | Shows how to use different layouts for group nodes using the recursive group layout. |
|**Hierarchical Layout with Sequence Constraints** | This demo shows how to customize the order of the nodes within a layer (sequencing) when using HierarchicalLayout. |
|**Basic Tree Layout** | Shows common configuration options for the tree layout. |
|**Tree Layout with Subtree Placers** | Shows how to use different subtree placers in tree layout. |

## Running the Demos

### With Visual Studio

* To load all samples into Visual Studio you can simply open the solution file yFiles Demos.sln. 
* To load a single sample into Visual Studio you can open the project file (.csproj) in the sample's directory.
