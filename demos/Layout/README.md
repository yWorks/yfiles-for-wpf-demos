# Layout Demos
These source code samples demonstrate the basic usage of the yFiles WPF layout algorithms to assign coordinates to your graph elements. For more complex examples, please see the samples in [yFiles WPF Showcase demos](../Showcase). Examples which don't use the yFiles WPF viewer components are shown in the [yFiles WPF LayoutOnly demos](../LayoutOnly/LayoutOnly.md). 

You will find the following programming samples in this package: 


| Name | Description |
|:---|:---|
|**AbortHandler** | This demo shows how to use an `AbortHandler` to abort layout algorithms running in a separate thread. |
|**Arc Diagram** |Shows how to visualize a graph as an arc diagram. |
|**Biofabrics** |A showcase of and introduction to simple, interactive biofabric visualization. |
|**Boundary Labeling** | Shows how to configure organic layout for annotating points on a diagram. |
|**Bus Routing** |Shows how to group edges in bus structures. |
|**Circular Substructures** | Shows circular layout, and its substructures and node types features. |
|**Clear Marquee Area** | Shows how to automatically keep a marquee area clear of graph elements. |
|**Clear Rectangle Area** | Shows how to automatically keep a user-defined rectangular area clear of graph elements. |
|**Critical Paths** | The hierarchical and tree layout styles can emphasize critical (important) paths by aligning their nodes. |
|**Custom Layout Stage** | Custom layout stages can be used to solve unique layout problems that are not adequately covered by existing layout algorithms. |
|**Edge Bundling** | Shows how edge bundling can be applied for reducing visual cluttering in dense graphs. |
|**Edge Grouping** | The hierarchical layout can group the paths or ports of edges. |
|**Edge Label Placement** | Shows how to place edge labels at the preferred location with a labeling algorithm. |
|**EdgeRouter Grouping** | The EdgeRouter can group the paths or ports of edges. |
|**Fill Area Layout** |Shows how to fill free space after deleting nodes. |
|**Folding With Layout** | Shows how an automatic layout makes space for opening groups and reclaims the space of closing groups. |
|**Height Profile** |Shows how to configure organic layout to create height profile visualization |
|**Hierarchical Layout with Exact Coordinates** | Shows how to configure hierarchical layout from sketch with exact coordinates. |
|**Hierarchical Grid Components** | Grid components in the hierarchical layout result in more compact arrangements. |
|**Hierarchical Nesting** |The hierarchical layout nicely expands and collapses sub-graphs organized in groups. |
|**Hierarchical Nesting (Incremental)** | Shows how to nicely lay out newly loaded nodes when expanding folded groups. |
|**Hierarchical Subcomponents** | The hierarchical layout can arrange subcomponents with different layout styles. |
|**Interactive Edge Routing** | After each edit the edge paths are re-routed if necessary. |
|**Interactive Hierarchical Layout** | The from sketch mode of the hierarchical layout style can incrementally fit new nodes and edges into the existing drawing. |
|**Interactive Organic Layout** |Shows the 'interactive organic' layout algorithm. |
|**Layer Constraints** | Shows how to use layer constraints to prescribe the node layering in hierarchical layouts. |
|**Layout Configurations** | This demo provides several configurations for layout algorithms to be used with the option handler as shown in the LayoutStyles demo. |
|**Maze Routing** |Shows how the automatic edge routing finds routes through a maze. |
|**Metabolic Pathways** |Shows how to configure organic layout for visualizing metabolic pathways. |
|**Multi-Page** | Shows how to use the multipage layout. |
|**Node Alignment** | Shows how to align nodes on horizontal and/or vertical lines. |
|**Automatic Node Labeling** | Shows how to place node labels at the preferred location with a labeling algorithm. |
|**Node Overlap Avoiding** | Shows how an automatic layout can remove node overlaps while a user interactively edits a graph. |
|**Node Types** | Shows how different layout algorithms handle nodes with types. |
|**Organic Substructures** | Shows organic layout, and its substructures and node types features. |
|**Partial Layout** |Shows how to integrate new graph elements into an existing graph layout. |
|**Port Alignment** |Shows how to implement port alignment in hierarchical layout to visualize paths. |
|**Sankey Diagram** | This demo demonstrates how HierarchicalLayout can be used to create Sankey diagrams. Sankey diagrams visualize flow information between entities and edge thickness is usually proportional to the flow quantity. |
|**Sequence Constraints** | Shows how to use sequence constraints to prescribe the node sequencing in hierarchical layouts. |
|**Simple Layout Grid** | Shows how to create a simple layout grid. |
|**Split Edges** | Shows how to align edges at group nodes using RecursiveGroupLayout with HierarchicalLayout. |
|**Tabular Groups** | Shows how to configure the tabular groups feature of the hierarchical layout. |
|**Tree Map** |Shows disk usage of a directory tree with the Tree Map layout. |
|**Layout Without View** |Shows how to use the graph analysis and layout algorithms without a view and without the IGraph API |

## Running the Demos

### With Visual Studio

* To load all samples into Visual Studio you can simply open the solution file yFiles Demos.sln. 
* To load a single sample into Visual Studio you can open the project file (.csproj) in the sample's directory.
