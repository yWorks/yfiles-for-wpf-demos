# Layout Styles

![Demo thumbnail](../../DemoBrowser/DemoBrowser/Screenshots/layout-styles.webp "Layout Styles")

This demo demonstrates the automatic layout algorithms shipped with yFiles
      and how the different settings affect the generated layout.
        
**Note: **This demo depends on the layout configurations from the `yWorks.Demo.Layout.Configurations`
      programming sample and on the option editor from the sample `yWorks.Demo.Toolkit.OptionHandler`.
