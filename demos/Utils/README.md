# Utility Projects for Demos
Utility projects for common functionality in demos. 

You will find the following programming samples in this package: 


| Name | Description |
|:---|:---|
|**Aggregation** | A demo library that provides an IGraph implementation to wrap a large graph and provide a smaller graph by replacing groups of nodes with single nodes. |
|**Demo Toolkit** | Support project for several demo applications. This projects provides common UI styles. |
|**Option** | This demo implements a generic framework to display and edit settings. <br />It is used by several other demos, such as <c>yWorks.Demo.Modules</c> and <c>yWorks.Demo.GraphEditor</c>. **This is legacy only code for older demos and should not be used as a starting point for new projects. Use the <c>yWorks.Demo.Toolkit.OptionHandler</c> demo instead**

|
|**Option Handler** | Support project for the `yWorks.Demo.LayoutStyles` demo. It provides an editor for the `yWorks.Demo.Layout.Configurations`. |

## Running the Demos

### With Visual Studio

* To load all samples into Visual Studio you can simply open the solution file yFiles Demos.sln. 
* To load a single sample into Visual Studio you can open the project file (.csproj) in the sample's directory.
