# Option

![Demo thumbnail](../../DemoBrowser/DemoBrowser/Screenshots/Option.webp "Option")

This demo implements a generic framework to display and edit settings.
		  
It is used by several other demos, such as `yWorks.Demo.Modules` and
		`yWorks.Demo.GraphEditor`.
		
**This is legacy only code for older demos and should not be used as a starting point for new projects. Use the <c>yWorks.Demo.Toolkit.OptionHandler</c> demo instead**
