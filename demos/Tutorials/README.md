# Tutorials
The yFiles WPF tutorials provide step-by-step introductions to the concepts and the features of the yFiles WPF diagramming library. It is intended for developers that want to get started with the library in general or particular features in an effective way. 

If you are new to the yFiles WPF diagramming library, it is recommended to start by going through the basic features tutorial and then through the other tutorials on demand. To make full use of the tutorial, it is also recommended to review and possibly modify the source code for each sample project. 



You will find the following programming samples in this package: 


| Name | Description |
|:---|:---|
|**Tutorial: Basic Features** |Learn about the most commonly used yFiles features. |
|**Tutorial: Graph Builder** |Learn how to convert business data into a graph using the GraphBuilder class. |
|**Tutorial: Edge Style Implementation** |Learn how to implement a custom edge style using DrawingVisual. |
|**Tutorial: Label Style Implementation** |Learn how to implement a custom label style using WPF drawing APIs. |
|**Tutorial: Node Style Implementation** |Learn how to implement a custom node style using DrawingVisual. |

## Running the Demos

### With Visual Studio

* To load all samples into Visual Studio you can simply open the solution file yFiles Demos.sln. 
* To load a single sample into Visual Studio you can open the project file (.csproj) in the sample's directory.
